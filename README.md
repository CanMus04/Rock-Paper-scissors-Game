# ✊🖐✌ Rock, Paper, Scissors – Terminal Game

A simple but fun command-line game built in Python.  
You play against the computer – first to 3 points wins!

---

## 🧠 About the Project

I built this project mainly to practice control flow, user input, and implementing simple game logic. Even though Rock, Paper, Scissors is a basic game, getting the flow to feel responsive and readable in the terminal was a good challenge.

The most interesting part was adding delays to build a bit of suspense before the computer makes its choice. That small touch made the game more interactive.

This game also helped me get better at working with loops, conditional statements, and basic Python functions.

---

## ✨ Features

- 🧠 Computer chooses randomly between Rock, Paper, or Scissors  
- 🧍 You choose using number input (1–3)  
- 🔄 Keeps track of score (first to 3 wins)  
- ⏳ Adds dramatic pause before computer move  
- 🚫 Validates user input

---

## 🛠️ How It Works

1. Player chooses Rock, Paper, or Scissors  
2. Computer randomly selects its move  
3. The winner is determined by standard rules  
4. Score is tracked until one side reaches 3 points  
5. Game ends with a final result and thank-you message

---

## 🧰 Technologies Used

- Python 3  
- `random` and `time` modules (standard library)
